# Neural Network MNIST

Et neuralt netværk implementeret fra bunden med Python og NumPy.

Projektet bruger MNIST-datasættet til at træne et simpelt neuralt netværk til at genkende håndskrevne cifre fra 0 til 9.

Formålet med projektet er først og fremmest at forstå de grundlæggende principper bag neurale netværk ved selv at implementere dem i stedet for at bruge et machine learning-framework.
